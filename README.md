# lx_sundhed

Sundhed- og aktivitetstracker app til LB-Phone.

### Features
- **Vågen i**: Tracker spillerens session/vågen-tid for indeværende dag.
- **Skridt**: Realistisk skridttæller til fods.
- **Kørt i bil**: Afstand tilbagelagt i køretøj (m / km).
- **Puls**: Dynamisk BPM baseret på bevægelse, sprinting, kørsel og skudveksling.
- **Mål**: Konfigurerbart dagligt skridtmål med progress ring.
- **Indstillinger**: Mulighed for at nulstille dagens data.
- **Performance**: NUI-optimeringer, KVP-caching, 0.00ms ressourceforbrug.

### Installation
1. Tilføj `ensure lx_sundhed` til din `server.cfg` efter `lb-phone`.
2. Genstart serveren eller kør `ensure lx_sundhed`.
